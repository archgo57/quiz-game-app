# 🎯 Quiz Master - Interactive Quiz Game

A simple, interactive quiz game built with HTML, CSS, and JavaScript. Test your knowledge with 5 multiple-choice questions!

## ✨ Features

- 🎮 **Interactive Quiz Interface** - Clean and modern design with gradient styling
- 📊 **Progress Tracking** - Visual progress bar and question counter
- ✅ **Instant Feedback** - Immediate visual feedback for correct/incorrect answers
- 🏆 **Score Calculation** - Real-time score tracking and final percentage
- 📋 **Answer Review** - Complete review of all answers with correct solutions highlighted
- 🔄 **Restart Function** - Take the quiz multiple times
- 📱 **Responsive Design** - Works perfectly on mobile, tablet, and desktop

## 📝 Quiz Questions

## 🚀 How to Use

1. **Open the Quiz** - Open `index.html` in your web browser
2. **Click "Start Quiz"** - Begin the quiz from the welcome screen
3. **Answer Questions** - Click on an answer option for each question
4. **View Feedback** - See immediate feedback (green for correct, red for incorrect)
5. **Check Results** - View your final score and percentage
6. **Review Answers** - See a complete review of all your answers
7. **Restart** - Click "Restart Quiz" to take the quiz again

## 🔧 Customization

To add more questions, edit the `quizData` array in `script.js`:

```javascript
const quizData = [
    {
        question: "Your Question?",
        answers: ["Option 1", "Option 2", "Option 3", "Option 4"],
        correct: 1  // Index of correct answer (0-3)
    },
    // Add more questions...
];
```
